# 🎨 Лендинг-визитка фрилансера

Адаптивный одностраничный сайт-визитка на чистом **HTML и CSS** — без фреймворков и сборщиков. Презентует услуги, портфолио и контакты.

## ✨ Особенности
- 📱 **Адаптивность** — корректно выглядит на телефоне, планшете и десктопе
- 🎨 Современный дизайн: градиентные акценты, плавные анимации, «стеклянная» шапка
- ⚡ Чистый код без зависимостей — мгновенная загрузка
- 🔗 Секции: Hero, Услуги, Портфолио, Контакты

## 🛠️ Стек
`HTML5` · `CSS3` (Grid, Flexbox, переменные) · адаптивная вёрстка (mobile-first медиазапросы)

## 🌐 Демо
Сайт опубликован через **GitHub Pages**:
👉 https://srgchprnn-ops.github.io/landing-page/

## 🚀 Запуск локально
Просто откройте `index.html` в браузере — никаких установок не требуется.
